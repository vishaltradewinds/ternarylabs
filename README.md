# A Chip Odyssey / Ternary Labs

A research-first initiative to test whether alternative numerical representations and specialized architectures can improve useful computing efficiency.

## Operating rule
No performance, energy, accuracy, or novelty claim is accepted without reproducible evidence and a fair baseline.

## Phase 0
Establish a low-cost, reproducible ternary-weight experiment. The first experiment measures representation size and output error; it does **not** claim hardware speedup.
